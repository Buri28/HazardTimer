# HazardTimer

> 試作段階 現時点でリリースはありません

壁に衝突した地点やFAILした地点などの**危険地帯までの秒数**をカウントダウン表示するMODです。  

しゃがみ壁は、気付いてから反応しても間に合わないことがあります。  
到達までの秒数が事前に分かれば、しゃがむ準備ができます。  
危険地点はマニュアルでも設定できますが、ローカルにBeatLeaderのリプレイデータがあると自動で取り込まれてカウントダウン対象になります。

<img width="40%" height="40%" alt="image" src="https://github.com/user-attachments/assets/b0e2db18-1a2d-4f6e-b47b-1a650226741b" />

## 何を危険地点とするか

譜面を解析して「しゃがみ壁かどうか」を判定するのではなく、
**実際に当たった場所・落とした場所を記録して、次回そこを警告します。**

| 種別 | 記録のされ方 | 表示 |
|---|---|---|
| **壁** (WALL) | 壁に接触した地点 | プレイ中に自動記録＋リプレイから取り込み |
| **フェイル** (FAIL) | 体力ゼロになった地点（1譜面につき1箇所） | プレイ中に自動記録＋リプレイから取り込み |
| **ミス** (MISS) | ノーツを落とした（見逃し・切り損ね）地点 | リプレイからの取り込みのみ |
| **ボム** (💣BOMB💣) | 爆弾に当たった地点 | リプレイからの取り込みのみ |
| **手動** (MARK) | 分と秒を指定して自分で追加 | 曲選択画面から追加 |

表示設定にかかわらず記録は行われます。出す・出さないは種別ごとの表示設定で切り替えます。
ただし BeatLeader / ScoreSaber でリプレイを再生している間は記録しません
（自分のリプレイなら取り込み済みのものを二度数えることになり、
他人のリプレイなら当たってもいない壁が残るため）。カウントダウンの表示はそのまま行います。

近い時刻に固まった記録は **1つの危険地点** としてまとめ、その中の1つだけをカウントダウンします
（まとめる幅は `Merge Interval`、既定5秒）。
壁は先頭を、フェイルは最も遅い地点を採ります。
これは自動で選ぶときの話で、`Turn On` で指定したものは 1 箇所に何個あっても全部使います。

デフォルト設定では到達の **10秒前** からカウントダウンが始まります。
表示は1行なので、10秒以内に前のマーカーがあるときは、そこを通過した時点から次のカウントダウンに切り替わります
（13秒・15秒・17秒にマーカーがあるなら、3～13秒・13～15秒・15～17秒）。

## 表示

カウントダウンは **Counters+ のカスタムカウンター** として表示されます。
`Mod Settings → Counters+` の一覧から **Hazard Timer** を有効にしてください。

<img width="50%" height="50%" alt="image" src="https://github.com/user-attachments/assets/41b815e5-437f-4956-b056-55a2c16d2a8b" />

表示は最大2行です。フェイル地点は専用の行として上に出し、
それ以外（壁・ミス・ボム・手動）は最も近い1つを下の行に出します。

プレイ中に文字を読む余裕はないので、**種別は色で見分けます。**

| | 遠いとき |
|---|---|
| フェイル | シアン |
| 壁 | ベージュ |
| ミス | 黄緑 |
| ボム | 紫 |
| 手動 | 白 |

残り **5秒** を切ると黄（フェイルはオレンジ）、**2秒** を切ると赤になります。

表示位置は `Mod Settings → Counters+ → Hazard Timer` の
`Counter X Offset` / `Counter Y Offset` で調整します。

## 使い方

壁への接触とフェイルは、プレイするだけで自動的に記録されます。

マーカーの確認・編集は、曲選択画面の左パネル **Mods タブ → HazardTimer** で行います。

<img width="50%" height="50%" alt="image" src="https://github.com/user-attachments/assets/72c2a06a-cffa-4feb-a91c-f9e64677e1c2" />

左の一覧に、選択中の譜面のマーカーが時刻順に並びます。
各行には種別・回数・状態が出ます（`MISS x2.3 On` など。回数はミスなら1プレイあたりの平均個数、
壁やボムなら当たったプレイ数）。

状態は**実際にカウントダウンされるかどうか**を表します。

| 状態 | 意味 |
|---|---|
| `On` | カウントダウンされる |
| `Off` | `Turn Off` で外した |
| `Hidden` | 種別の表示設定（`Show ～`）が切られている |
| `Dup` | 同じ地点の別のマーカーが使われている |

| 操作 | 内容 |
|---|---|
| **Import** | この譜面をローカルのリプレイから取り込み直す |
| **Delete All** | この譜面のマーカーを全部消し、自動取り込みも止める |
| **Add** / **Update** / **Delete** | 分・秒・ラベルを指定してマーカーを追加／更新／削除 |
| **Turn On** | そのマーカーを必ずカウントダウンに使う（ほぼ同時刻に重なる他だけ使わなくなる） |
| **Turn Off** | そのマーカーだけ、消さずに使わないようにする |
| **All Off** | この譜面の全マーカーを、消さずに使わないようにする |
| **All Auto** | この譜面に付けた On / Off の指定を全部外し、自動選択に戻す |

ラベルを空にすると、種別ごとの既定（WALL / FAIL / MISS / BOMB / MARK）になります。

マーカーは `UserData/HazardTimer/markers.json` に保存されます。

### 過去のリプレイから取り込む

実測方式なので、そのままだと初めて遊ぶ譜面では何も表示されません。
BeatLeader MOD を使っていれば、**曲を選んだ時点で過去のプレイ記録から自動で取り込みます。**

**通信は行いません。** `UserData/BeatLeader/Replays` にあるファイルを読むだけです。

新しいものから既定10件までを読みます。一度読んだファイルは覚えているので、
遊ぶたびに増えた分だけが積み上がります。

- **壁・フェイル** … 見つかった地点をそのまま取り込みます。
- **ミス** … 数が多いので、**複数のプレイで重なっている箇所ほど上位**として既定10箇所まで。
  使う指定になるのは最も多く落としている1箇所だけで、残りは候補として使わない指定で入ります。
  必要になったら `Turn On` で切り替えてください。
- **ボム** … ミスほど当たらず、当たると立て直しが利かないので、取り込んだ分は既定で全部使います（既定5箇所まで）。

NoFail を付けていると、ゲームはどこで落ちていたかを記録しません。
HazardTimer はゲーム本体と同じ規則で体力を数え直し、その地点をフェイルマーカーにします。

## 設定

Mods タブの `Settings` ボタンから変更できます。

<img width="50%" height="50%" alt="image" src="https://github.com/user-attachments/assets/2e412c07-8c58-426c-b578-76b3fdb27898" />

| 項目 | 内容 | 既定 |
|---|---|---|
| Countdown Time | 何秒前からカウントダウンを表示するか | 10秒 |
| Merge Interval | この秒数未満で続く記録を1つの危険地点にまとめる | 5秒 |
| Show Fail Marker | フェイル地点をカウントダウンに出す | ON |
| Show Miss Markers | ミス地点をカウントダウンに出す | ON |
| Show Bomb Markers | ボム被弾地点をカウントダウンに出す | ON |
| Show Wall Markers | 壁への接触地点をカウントダウンに出す | ON |
| Auto Import Replays | 曲を選んだときリプレイから自動で取り込む | ON |
| Max Import Replays | 1譜面あたり何件のリプレイを読むか（新しい順） | 10件 |
| Max Miss Markers | 1譜面あたり何個までミス地点を取り込むか（0で取り込まない） | 10個 |
| Max Bomb Markers | 1譜面あたり何個までボム地点を取り込むか（0で取り込まない） | 5個 |

`Show ～` は全譜面に効きます。切っても記録・取り込み・一覧には影響しません。
譜面ごと・マーカーごとの On / Off は一覧の `Turn On` / `Turn Off` で行います。

## 必要なMOD

- BSIPA
- BeatSaberMarkupLanguage
- SiraUtil
- Counters+

BeatLeader は必須ではありません。入っている場合のみ、リプレイの取り込みが使えます。

## 大会での使用について

本MODは **「プレイ中にマップの情報を表示するMOD」に該当します。**
BSWC をはじめとする多くの大会では、この種のMODは禁止されています。
大会に参加する際は必ず外してください。
