# HazardTimer

**試作段階**

譜面中の**危険地点までの残り秒数**をカウントダウン表示する Beat Saber 用MODです。

しゃがみ壁は腕の動作と違って予備動作が必要なので、気付いてから反応しても間に合わないことがあります。
到達までの秒数が事前に分かれば、しゃがむ準備ができます。

> **開発中です。** まだ動作するリリースはありません。

## 何を危険地点とするか

譜面を解析して「しゃがみ壁かどうか」を判定するのではなく、
**実際に当たった場所を記録して、次回そこを警告します。**

譜面から判定しようとすると、演出用の装飾壁や分割配置された壁を実際の障害物と区別できず、
警告だらけになってしまいます。一方、接触したという事実は「対応できなかった」ことの証明なので、
記録された地点は自然と「**予期できなかった危険**」だけに絞られます。

しゃがみ前提の譜面では構えているので当たらず、マーカーも増えません。
ほぼ壁のない譜面に1枚だけ紛れている壁こそが記録されます。

## 表示されるマーカー

| 種別 | 記録のされ方 |
|---|---|
| **壁** | 壁に接触した地点 |
| **フェイル** | フェイルした地点（1譜面につき1箇所） |
| **手動** | 分と秒を指定して自分で追加 |

- 規定では到達の **10秒前** からカウントダウンが始まります（変更可）。
- 連続した壁は1つにまとめられます。次の壁が既に視界に入っているなら、警告はかえって邪魔になるためです。
- 記録は譜面ごとに保存されます。譜面が更新された場合は破棄されます。

## 使い方

カウントダウンは **Counters+ のカスタムカウンター** として表示されます。
`Mod Settings → Counters+` の一覧から **Hazard Timer** を有効にし、表示位置を調整してください。

壁への接触とフェイルは、プレイするだけで自動的に記録されます。

マーカーの編集は、曲選択画面の左パネル **Mods タブ → HazardTimer** で行います。
左に記録されているマーカーの一覧、右に編集欄が並びます。

一覧からマーカーを選ぶと、その名前と時刻が右の入力欄に読み込まれます。

| ボタン | 動作 |
|---|---|
| `Delete` | 選択中のマーカーを消す |
| `Update` | 選択中のマーカーに、入力欄の内容を書き戻す |
| `Add` | 入力欄の内容で新しいマーカーを追加する |
| `Import` | この譜面のリプレイから取り込み直す |
| `Delete All` | この譜面の記録をすべて消し、自動取り込みも止める |
| `Settings` | 設定を開く |

`Label` はマーカーに付ける表示名です。空にすると種別ごとの既定
（`WALL` / `FAIL` / `MARK`）になります。

> 表示は TextMeshPro の既定フォントで描かれるため、日本語などは字形が無く
> 正しく表示されない可能性があります。英数字を推奨します。

### 消したマーカーは戻せるか

| 種別 | `Import` で戻るか |
|---|---|
| 取り込みマーカー | **戻ります** |
| 実測マーカー | その回のリプレイが残っていれば、取り込みマーカーとして戻ります |
| 手動マーカー | **戻りません** |

自動取り込みでは戻りません（リプレイの件数が変わらないため再取り込みが走りません）。
消した状態はそのまま保たれ、`Import` を押したときだけ作り直されます。

### 過去のリプレイから取り込む

実測方式なので、そのままだと**初めて遊ぶ譜面では何も表示されません**。
BeatLeader MOD を使っていれば、過去のプレイ記録から接触地点を埋められます。

**曲を選ぶと自動で取り込まれます。** `UserData/BeatLeader/Replays` にある
その譜面のリプレイだけを読みます。**通信は行いません。**
ローカルに保存済みのファイルを読むだけです。

自動取り込みは Mods タブの `Settings` にある `Auto Import Replays` で切れます。
切った場合や、記録を消したあとに取り込み直したい場合は、Mods タブの
`Import` を押してください。

その譜面を新しく遊んでリプレイが増えると、自動的に取り込み直されます。
`Delete All` で記録を消した譜面は、以後その譜面だけ自動取り込みの対象外になります。
`Import` を押せば解除されます。

同じ譜面のリプレイが複数ある場合、扱いはマーカーの種類で違います。

- **壁マーカーは全リプレイから集めます。** 過去に一度でも当たった地点は等しく危険なので、
  絞り込みません。近い時刻のものは1つに統合されます。
- **フェイルマーカーは1件だけ見ます。** 最後に完走したプレイを選び、完走が1つも無ければ
  最後の未完走を選びます。**選んだプレイで落ちていなければ、他のプレイで落ちていても
  マーカーは立ちません。** 今の実力で通せる譜面に警告は要らないためです。

取り込んだマーカーは実測と区別して保持され、同じ地点で実際に接触するとそちらで上書きされます。

### NoFail でのフェイル地点について

NoFail を付けていると、ゲームは体力を一切減らしません。そのため
**どこで落ちていたかはゲームにもリプレイにも記録されていません。**

HazardTimer はゲーム本体と同じ計算規則で体力を裏で数え直し、ゼロになった地点を
フェイルマーカーにします。プレイ中と、リプレイの取り込みの両方で行います。

実際のプレイ記録 4355 件（NoFail なし＝落ちていないことが確定しているもの）で検算したところ、
誤って「落ちた」と判定したのは 11 件（0.25%）でした。その大半は、壁の中にいる状態で
曲を途中終了したケースです。

記録は `UserData/HazardTimer/markers.json` に保存されます。

カウントダウンの開始秒数や、壁をまとめる閾値は Mods タブの `Settings` から変更できます。
Counters+ の設定画面には表示位置の調整だけを置いています。

## 必要なMOD

- BSIPA
- BeatSaberMarkupLanguage
- SiraUtil
- Counters+

BeatLeader は必須ではありません。入っている場合のみ、リプレイの取り込みが使えます。

## 大会での使用について

本MODは **「プレイ中にマップの情報を表示するMOD」に該当します。**
BSWC をはじめとする多くの大会では、この種のMODは禁止されています。
大会に参加する際は必ず外してください。
